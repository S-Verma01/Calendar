# Calendar Application
  Desktop calendar application with multiple features.

## Current Features
- Create calendar entries
- Delete calendar entries
- Edit calendar entries
- Mini calendar for date selection
- Appointment overview with countdown 

## Technologies Used
- Java 21
- JavaFX
- JavaFX CSS
- JDBC SQLite
- Maven
- CalendarFX
- AtlantaFX

## Project Status
Every feature implements the core functionality, further improvements and additional features are planned.
